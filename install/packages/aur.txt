# The AUR package manifest.
#
# The packages an xghost desktop needs that no official Arch repository carries.
# The format is the format of base.txt beside this file.
#
# This file declares no package today, and that is a fact about this
# installation rather than a gap in it: every package the two bundles need is in
# core or extra. hyprshot is the one the bundle page and the dotfiles both call
# an AUR package, and 'pacman -Si hyprshot' answers 'extra', so it is in
# base.txt with the rest.
#
# The file and its packaging step stay, because the repository a package comes
# from decides which tool installs it, and a later bundle will name one that
# only the AUR carries: hyprshade, which issue #17 owns, has no official package
# at all. Expressing that as a second manifest rather than as a marked line in
# base.txt keeps the decision out of a comment. A comment is text the parser
# drops, so a comment must never be what decides which program runs against a
# package name.
#
# The base installation therefore requires no AUR helper. When this file names a
# package and no helper is installed, the packaging step names that package,
# says what it serves, and lets the installation finish: xghost installs no AUR
# helper by itself, because that would mean building a PKGBUILD nobody vetted on
# a machine that asked for a desktop.
