# The base package manifest.
#
# Every package an xghost desktop needs from an official Arch repository. This
# file is the single source of truth for those dependencies: the packaging step
# installs exactly what is here, and nothing installs a package this file does
# not name.
#
# The format:
#
#   - One package per line.
#   - A '#' starts a comment. It may open a line or follow a package name.
#   - An empty line is allowed, and the white space at both ends is dropped.
#
# A comment carries no meaning to the installer. The file a package is in is
# what says which tool installs it: pacman installs this file, and an AUR helper
# installs aur.txt beside it. docs/installing.md records why the two are two
# files.
#
# Where the list comes from:
#
#   - The package table of each bundle page under docs/bundles/.
#   - The dependency tables of qdrtech/dotfiles, docs/installation.md, section
#     "Required for the desktop session".
#
# One name moved between the two manifests. Both of those tables call hyprshot
# an AUR package, and it is in the 'extra' repository today, so pacman installs
# it and the base installation needs no AUR helper for it. 'pacman -Si hyprshot'
# names the repository.
#
# What is not here:
#
#   - A package a later bundle owns. Each bundle adds its own line here when it
#     lands.
#   - A package of the Arch 'base' group, such as util-linux for 'flock' and
#     systemd for 'localectl'. Every Arch installation already has those, and
#     declaring them would say that this project chose them.

# The terminal. docs/bundles/ghostty.md.
ghostty

# The compositor and its daemons. docs/bundles/hyprland.md.
hyprland
hypridle
hyprlock
hyprpaper

# What a desktop session needs behind the compositor.
xdg-desktop-portal            # the portal front end
xdg-desktop-portal-hyprland   # the backend, for screen sharing
polkit-gnome                  # the authentication agent

hyprshot                      # the two screenshot keybindings
psmisc                        # killall, in the two restart keybindings
wireplumber                   # wpctl, in the volume keybindings
brightnessctl                 # the brightness keybindings
playerctl                     # the media keybindings
network-manager-applet        # nm-applet, in the autostart
blueman                       # blueman-applet, in the autostart
nautilus                      # $fileManager

# The bar, and the two programs its modules run. docs/bundles/waybar.md.
waybar
pacman-contrib                # checkupdates, in the module that counts updates
networkmanager                # nmtui, in the module that opens the network

# The fonts KNOB_FONT offers. The default is the first. The second is here
# because a font a knob offers and the machine does not carry falls back in
# silence, which is the one failure a knob must not have.
ttf-jetbrains-mono-nerd
ttf-cascadia-code-nerd

# What xghost itself reads. 'xdg-settings' is the source of the default browser
# in the machine facts. docs/machine-facts.md, "Where each fact comes from".
xdg-utils

# What xghost itself writes. The background of a theme is a raster image, and
# nothing else in this file can write one. lib/background.py draws it with the
# standard library of Python alone: no image library is installed and none is
# used. docs/backgrounds.md carries the vetting of this line, the alternative
# that was weighed against it, and the two facts that decided it: 'python' is
# already in the dependency tree of blueman and nautilus above, so this
# declares a package every xghost machine installs already, and imagemagick
# would add four packages and a far larger surface.
#
# The maintainer read that vetting and approved this line on 2026-08-14.
python

# The shell, the prompt and the multiplexer. docs/bundles/shell.md.
zsh
starship
tmux
zsh-syntax-highlighting       # the highlighter the prescribed zshrc sources
zsh-autosuggestions           # the suggestions the prescribed zshrc sources

# The launcher. docs/bundles/rofi.md.
#
# 'rofi' provides and replaces 'rofi-wayland', so the compositor of this desktop
# needs no second package. No icon theme is here: 'hicolor-icon-theme' is a hard
# dependency of rofi itself and 'adwaita-icon-theme' is one of gtk3, which the
# bar already needs, so declaring either would say that this project chose it.
rofi

# The notification centre. docs/bundles/swaync.md.
#
# Every program its buttons run is already above: wireplumber for 'wpctl',
# ghostty for the terminal the network button opens, networkmanager for the
# 'nmtui' inside it, blueman for 'blueman-manager', and hyprlock. 'swaync-client'
# is in this package, and the bell of the bar runs it. No package is added for
# gtk4 or libpulse: both are hard dependencies of swaync itself, so declaring
# either would say that this project chose it.
swaync

# The GTK theme, the icon theme and the cursor theme config/gtk-3.0/settings.ini
# names. docs/bundles/supporting.md.
#
# All three are here rather than in aur.txt on purpose. A theme in aur.txt is
# not installed on a machine with no AUR helper, the installation finishes and
# says so, and GTK then falls back to the built-in Adwaita without a word. The
# dotfiles this bundle comes from named Tokyonight-Dark and Tokyonight-Moon,
# which one AUR package provides, and that is the failure this line avoids.
#
# 'default-cursors' is declared although wayland already depends on it, which
# is against the rule about a package the tree carries anyway. The rule is
# about a package nobody names. This project names the theme in settings.ini,
# so this project chose it.
adw-gtk-theme                 # adw-gtk3-dark, the widget theme
papirus-icon-theme            # Papirus-Dark, the icon theme
default-cursors               # the name 'default', redirected to Adwaita
